# CRM Canarias · Compagnie des Desserts

App de visitas comerciales para iPhone y portátil.

## Abrir en el móvil

Cuando GitHub Pages termine:
https://balmorju-png.github.io/crm-cdd-canarias/

En Safari: Compartir → Añadir a pantalla de inicio.

## Primera vez

1. Crea un proyecto en https://supabase.com
2. SQL Editor → pega `supabase/000_todo.sql`
3. Authentication → Email ON y Confirm email OFF
4. Settings → API: copia URL y anon key en la pantalla inicial de la app
5. Crea tu usuario
